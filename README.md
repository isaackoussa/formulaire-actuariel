# LinguaPro — Anglais professionnel

Application d'anglais pour la finance, le droit, la comptabilité, la banque, l'assurance/actuariat, le business, les réunions/négociations et la carrière. 100 % navigateur (aucun serveur, aucune variable d'environnement), installable sur l'écran d'accueil et utilisable hors ligne.

## Déploiement (Netlify)

Le dépôt est déjà prêt : `netlify.toml` publie le dossier `public/`. Un push sur `main` suffit ; sinon **Deploys → Trigger deploy → Deploy site**.

## Contenu

8 domaines, 147 termes (définition, exemple, traduction), 11 dialogues, 8 exercices d'écoute, 8 leçons vidéo narrées, 7 fiches de grammaire pro, 25 phrases de prononciation.

## Fonctionnalités

- 🔊 Audio partout (accent américain, britannique, australien ou indien ; vitesse réglable ; mode lent 🐢)
- 🎙️ Exercices vocaux notés mot par mot (reconnaissance vocale de Chrome/Safari ; ailleurs, enregistrement + auto-évaluation)
- 🎭 Jeux de rôle : l'app joue un personnage, vous répondez au micro (mode défi : texte masqué)
- 🎬 Leçons vidéo narrées avec texte karaoké et sous-titres FR, plus des liens vers des vidéos YouTube par sujet
- 🎧 Mode podcast mains libres (anglais → français → exemple, avec pause pour répéter)
- 🧠 Révision espacée (SM-2) : chaque mot revient au bon moment
- 8 types d'exercices : QCM, écoute, dictée, prononciation, phrases à trous, remise en ordre, association, cartes mémoire
- 🔥 Série de jours, XP, objectif quotidien, statistiques par domaine, glossaire avec recherche

## Modifier le contenu

Tout le contenu (vocabulaire, dialogues, écoutes, leçons, grammaire, phrases) est dans `public/data.js`.
